Run NOVA on your PC

  1. Install Python 3 and ComfyUI.
  2. Download this repository: GitHub → Code → Download ZIP.
  3. Start ComfyUI and confirm it opens at http://127.0.0.1:8188.
  4. Extract the ZIP and run start_nova_windows.bat (Windows), or python server.py.
  5. Open http://127.0.0.1:8000 in Chrome.
  6. Load an API-format workflow from the ComfyUI Wan examples.
